# Security

For a suspected vulnerability, use **Report a vulnerability** in this repository’s GitHub Security tab. Include the affected version, expected behavior, and the smallest redacted description that helps a maintainer investigate. Keep deployment addresses, keys, pairing links and conversation content out of reports and issues.

Asterhelm is designed for a single owner with trusted devices. Paired clients have access to that owner’s tasks and conversations. Worker enrollment, phone pairing and optional context sharing are described in [the self-hosting guide](docs/self-hosting.md). The latest public release receives security fixes.
