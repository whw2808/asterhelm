协作演示

展品目录里少了什么？

在这个虚构示例里，你让星舵关注展品目录的校对进展。桌面会话提到一份清单有缺项。看看这条线索如何变成一份交付。

桌面会话摘录 · 展品校对

“纸本目录缺少《玻璃器清单》，页码还待核对。”

星舵要查的问题 校对记录能否证实这项缺漏？

来源设备 / 校对 Agent

先核对记录中的依据

星舵请来源设备的 Agent 在隔离环境里只读核对这段摘录。每个候选事项最多自动查证一次。主聊天会显示查证结果和仍缺的材料。

你 / 主聊天

由你决定是否立项

候选卡建议整理缺项和依据。只有你明确同意，星舵才为它建立工作编号，或将它归入已有工作。你也可以忽略建议，或单独委托再查一次。

星舵 / 主聊天

把已知和待补的材料一起交回

校对 Agent 交回缺项报告，指出记录里缺的是《玻璃器清单》，具体页码仍待原册确认。任务卡保留负责的设备、Agent、耗时和报告，供你接着问。

手机界面

手里一个入口。
身后多台机器。

日常只和星舵对话。想看看谁在工作时，切到看板就能找到对应的设备、Agent 和会话。

在原问题下改要求

发一句“暂停电子版，纸本继续”，星舵就在同一工作里调整分工。任务卡会区分已请求撤回和执行端已确认停止，纸本的进度也留在这里。

从设备找到要接续的会话

看板按设备列出已注册的 Agent 和就绪状态。点开一个 Agent，可以查看任务，也可以选择要带回主聊天的会话。

星舵今天用了多少 token？

可以直接在聊天里问，也可以打开看板的“Token 用量”。这里列出总控今日和累计的输入、输出和合计，累计从启用统计时算起。看板会注明已知小计，以及有多少次调用上报不全。

长期协作

下次，从这里继续。

在原桌面会话说“继续”

你可以把选定的 Codex 会话加入同一件工作。启用桌面回执后，原窗口会收到摘要并确认收悉。你在那里说“继续”，它才按最新要求执行，回复也会回到手机。

约好时间，或等一次新回执

“每个工作日上午九点提醒我”和“每次校对任务失败都提醒我”都能登记为规则。自托管主机在线时，手机离线也能触发。重连后可以在原聊天补看、暂停或取消。

交代一件要持续做的事

告诉星舵“持续核对纸本目录，直到两册都核对完”。相关回执到达或到了下次检查时间，它就按最新范围跟进。两册都有核对依据后，它会交付结果，结束这项委托。
