协作演示

一个问题的去向。

把几条展品说明整理成分类索引，星舵会怎样派单？可以切换下方三个环节，查看这个虚构示例。

示例任务 · 资料整理

“给这组虚构展品做一份分类索引。”

示例条目 纸雕 / 木刻 / 玻璃器

移动端 / Asterhelm

先弄清要交付什么。

星舵从请求中提取要交付的内容：每件展品对应一个分类，最后形成一份可阅读的索引。

示例节点 B / 整理助手

交给能处理这份资料的 Agent。

整理助手接单，按材料归类。主聊天中的任务卡显示分给了哪个节点、哪个 Agent，以及它目前的进度。

Asterhelm / 移动端

把索引带回这场对话。

星舵汇总分类结果：纸雕归入纸艺，木刻归入木作，玻璃器归入玻璃工艺。之后还可以接着讨论分类标准。

手机界面

手里一个入口。
身后多台机器。

日常只和星舵对话。想看看谁在工作时，切到看板就能找到对应的设备、Agent 和会话。

进度就在原问题下方。

只读查询和执行任务都会留下派单卡。可以扫一眼耗时，也可以点开报告，再接着问。

按机器分栏，按 Agent 查看。

设备和 Agent 注册后出现在看板里。点进一张卡片，查看任务或带着选中的历史会话回到聊天。

长期协作

下次，从这里继续。

接上已有的会话

已经在某台设备上开始的会话，可以从手机找到。选中它，就能带着原先的上下文继续。

记住偏好与未完事项

把长期偏好和待跟进的事交代给星舵，下次聊同一件事时可以接着说。

该提醒时，来找你

约定的时间到了，或关注的会话发生变化，星舵可以发出系统通知，点开回到对应消息。
