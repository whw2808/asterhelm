# 跨设备工作接续实施计划

对应设计见 [跨设备接续同一件工作](../specs/2026-11-25-work-continuity.md)。基于现有 Node.js 24、SQLite、手机 WebView 和按设备认证的连接器。用虚构数据开展验证。

1. 在个人助手存储与派单回执旁增加工作绑定、追加式事件和按端确认。回归测试覆盖同一工作两轮更新、多个端、原有会话未绑定、重试及不串工作。
2. 手机选择「接着聊」后保留当前工作，提供明确的退出方式。仅让关联会话在绑定之后的新发言进入原手机对话。对桌面摘要自身做回流去重。
3. 用已注册的设备连接器取送待处理更新。桌面适配器验证共享服务、原线程、可见历史、繁忙状态与反馈循环。无法核实投递时保留积压，不自动在另一个会话执行。
4. 运行全套测试和 Android 构建，再用手机原 App 及桌面原生会话进行往返。分别记录用户发言前截图、说「继续」后的回答、手机收到的结果和意外副作用。
